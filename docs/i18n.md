# Internationalization

`i18n` means internationalization. For this project it means user-visible mechanical output must be selectable by locale.

Expected behavior:

- `locale: "zh-CN"` shows Chinese mechanical output.
- `locale: "en-US"` shows English mechanical output.
- Missing keys should fall back safely and emit a low-noise diagnostic.
- Protocol fields must not be translated.

Examples of translatable text:

- Status panels.
- Usage notices.
- Compaction notices.
- Error summaries shown to the chat user.
- Runtime detail block titles.

Examples of non-translatable text:

- JSON field names.
- app-server method names.
- XML pulse field names.
- File-delivery markers.
- Environment variable names.

## 国际化

这里的国际化指：用户可见的机械输出可以通过 `locale` 选择中文或英文。

应翻译：

- 状态面板。
- 命令用法提示。
- 上下文压缩提示。
- 展示给聊天用户的错误摘要。
- 运行细节标题。

不应翻译：

- JSON 字段名。
- app-server method。
- XML pulse 字段名。
- 文件交付标记。
- 环境变量名。
