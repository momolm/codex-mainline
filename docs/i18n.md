# Internationalization

Codex Mainline supports bridge-layer mechanical output in `zh-CN` and `en-US`.

## Configure Language

Set the default language in `config/codex-mainline.settings.json`:

```json
{
  "locale": "zh-CN",
  "fallback_locale": "zh-CN",
  "locales_dir": "locales"
}
```

Switch at runtime from Telegram:

```text
/language en-US
/language zh-CN
```

The command updates `locale` in the settings file and affects future bridge-layer command replies, status text, bot command descriptions, compaction notices, and fixed prompts.

## Locale Files

Locale catalogs live in:

- `locales/zh-CN.json`
- `locales/en-US.json`

When adding bridge-layer user-visible text, add a key in both files and read it through the locale helper instead of hardcoding text in the runner.

## Locale-Keyed Config Values

Text and prompt path settings can be plain strings or objects keyed by locale:

```json
{
  "rhythm_message_path": {
    "zh-CN": "prompts/rhythm_autonomous_action.zh-CN.md",
    "en-US": "prompts/rhythm_autonomous_action.en-US.md"
  }
}
```

Plain strings are treated as language-independent overrides. Use locale-keyed objects when the value is visible to users or injected into the model as fixed prompt text.
